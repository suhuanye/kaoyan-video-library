# 考研数学视频导航

适合手机和电脑的考研数学视频目录。按章节或关键词找到澄潇宇《数学大观》的讲解，点击时间跳到 B 站对应位置。

- 11 个章节，227 个章节片段，541 个细分考点。
- 原有数二内容完整保留，新增「数一数三专项」：级数大观、线面积分大观。
- 按章节浏览、跨章节搜索、细分考点 / 章节整段筛选。
- 搜索词、章节和筛选条件保留在网址中，可直接收藏或分享。
- 纯静态页面，无需安装依赖、启动后端或登录；也可直接打开 `index.html`。
- 时间区间用于导航，播放器从起点播放，不会在区间终点自动暂停。标有“约略定位”的考点时间尚有不确定性。

## 更新视频数据

在原工作区中运行：

```sh
node tools/export-videos.mjs
```

也可提供工作台数据文件路径：

```sh
node tools/export-videos.mjs /path/to/app-data.json
```

脚本只导出视频导航字段，不导出个人学习记录、任务、知识卡或本机路径，也不修改源数据。

更新页面、样式或视频后也运行一次导出脚本：它会按文件内容更新 CSS、脚本及视频数据的资源版本，避免浏览器把新版页面与旧目录缓存混用。网址保持不变。

导出后可运行 `node tools/check-data.mjs` 检查数量、重复 ID、视频时间、乱码及本机路径。

## 数一数三专项的时间依据

先找原视频评论区时间轴，再用实际分P及官方章节核对。核对记录与人工整理的标题保存在 `data/special-topics.json`，不按等时长拆分生成考点。

- **级数大观**：99 个细分时间点，来自一条评论及其四条回复，覆盖具体数项审敛、抽象数项审敛、收敛域、幂级数求和、函数展开。评论中的分P标注按当前视频标题校正；超时的 `11:27:18`、顺序异常的 `2:39` 未擅自修复。另收录 25 个视频官方章节。
- **线面积分大观**：截至 2026-10-27 仅公开前言、空间解析几何与场论初步、三重积分三个分P。评论中没有找到可信的完整细分时间轴，因此收录 7 个官方章节及三重积分的整段入口；未标明分P的单独时间点不发布。不要把课程名理解为曲线、曲面积分讲解已全部收录。
- 细分标题根据评论笔记提炼，视频未经逐题人工复看；每条新增内容都可点击来源返回评论或原视频。区间终点取下一评论坐标或所在官方章节终点，属于导航边界，不表示老师在该秒结束该题。

官方章节核对自 B 站原视频的分P列表及播放器章节：
[级数大观](https://www.bilibili.com/video/BV1THN36xE41/)、[线面积分大观](https://www.bilibili.com/video/BV1YPak6pEct/)。

## GitHub Pages

将此目录作为独立仓库上传。在仓库 **Settings → Pages** 选择 **Deploy from a branch**，分支 `main`，目录 `/ (root)`。

此后推送 `main` 会自动更新网页。官方说明：[配置 GitHub Pages 发布来源](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。
